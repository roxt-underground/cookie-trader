# Cookie trader

Люблю игру [Cookie Clicker](https://orteil.dashnet.org/cookieclicker/), и мне захотелось немного автоматизировать некоторые процессы в ней.
В мини игре банка ресурсы будут автоматически покупаться и продаваться для извлечения пассивного дохода из печенек.
Так же будет автоматом подгружен аддон CookieMonster.
